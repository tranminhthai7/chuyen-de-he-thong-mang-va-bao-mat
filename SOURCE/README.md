# SOURCE

Thư mục này dành cho mã nguồn do nhóm viết và dữ liệu thử nghiệm tổng hợp, giả lập.

Hiện chưa có code. Không đặt mã độc, exploit, công cụ lấy thông tin xác thực, dữ liệu cá nhân, log thô nhạy cảm hoặc file thực thi tải từ nguồn không rõ. Mọi script tương lai phải có mục đích phòng thủ, phạm vi lab và hướng dẫn kiểm thử được duyệt.
