# Firewall

Dùng thư mục này cho thông tin phiên bản đã xác minh, yêu cầu tài nguyên, ma trận rule và hướng dẫn backup/rollback.

Chưa ghi luật cấu hình thực thi. Rule chỉ được soạn sau khi chính sách, dịch vụ demo, chiều kết nối và đường quản trị được đặc tả, kiểm tra theo tài liệu đúng phiên bản và phù hợp yêu cầu môn học. Cấu hình private/nhạy cảm phải nằm trong `private/`, thư mục này bị Git bỏ qua.
