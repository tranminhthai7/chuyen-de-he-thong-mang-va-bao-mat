# Firewall

Dùng thư mục này cho thông tin phiên bản đã xác minh, yêu cầu tài nguyên, ma trận rule và hướng dẫn backup/rollback.

Chưa ghi luật cấu hình thực thi. Rule chỉ được soạn sau khi chính sách, dịch vụ demo, chiều kết nối và đường quản trị được giảng viên duyệt. Cấu hình private/nhạy cảm phải nằm trong `private/`, thư mục này bị Git bỏ qua.
