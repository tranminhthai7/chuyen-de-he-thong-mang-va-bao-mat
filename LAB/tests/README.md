# Tests

Mỗi ca kiểm thử cần ghi:

| Trường | Nội dung cần ghi |
| --- | --- |
| ID | Mã duy nhất của ca |
| Mục tiêu | Chính sách cần xác minh |
| Nguồn/đích | Máy ảo/vùng trong lab |
| Dịch vụ | Giao thức/dịch vụ bình thường đã duyệt |
| Kỳ vọng | Cho phép hoặc từ chối, kèm căn cứ |
| Kết quả | Chỉ điền sau khi chạy thực tế |
| Log/minh chứng | Đường dẫn tới bản đã làm sạch |
| Trạng thái | Chưa chạy / Pass / Fail / Cần điều tra |

Không đưa exploit, malware, phishing, credential attack, scan ngoài phạm vi hoặc kiểm thử DoS vào đây.
