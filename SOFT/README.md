# SOFT

Thư mục này chỉ dành cho phần mềm/phụ thuộc được phép phân phối kèm bài nộp.

Ưu tiên ghi tên, phiên bản và URL tải chính thức thay vì sao chép installer, ISO, sách có bản quyền hoặc file lớn vào repo. Trước khi đưa bất kỳ gói nào vào, phải xác minh giấy phép, nguồn gốc, checksum nếu có và yêu cầu của giảng viên.
